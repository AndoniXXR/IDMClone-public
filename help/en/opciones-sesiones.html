Options: Site logins

User names and passwords for servers or sites that require them. Each entry is a site (it may include a path and the * wildcard) with its user name and password; IDMClone uses them when downloading from that site.

  • New, Edit and Remove manage the list.
  • Passwords are stored encrypted for your Windows user.
  • A single download can also carry its own user name (Add URL > use authorization, or Properties).
