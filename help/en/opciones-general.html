Options: General

  • Launch IDMClone on Windows startup: it starts hidden in the notification area when you sign in.
  • Automatically start downloading URLs copied to the clipboard: when you copy a single address whose file type is in Options > File types, IDMClone downloads it.
  • Integrate into the Explorer context menu: adds "Download with IDMClone" to the right-click menu of Internet shortcuts (.url) and "Download links with IDMClone" to that of .txt, .htm and .html files, which opens the link list with the addresses found in the file (like Tasks > Import). The installer turns it on as well.
  • Capture downloads from the following browsers: in unchecked browsers the extension neither captures downloads nor shows the video panel, like IDM. The "Download with IDMClone" context menu still works. Add browser... adds another program to the list.
  • Keys...: keys that, held while clicking a link, prevent IDMClone from capturing the download or force it.
  • Customize the browser context menu: which IDMClone items appear in the right-click menu (Chromium and Firefox separately). "Download all links" is unchecked by default.
  • Show the download panel in browsers: the "Download this video" panel over media players. Edit... opens its settings (mode, minimum size, sites where it is not shown...).

The browser extension receives these settings from IDMClone; if it is not connected, the page says so.
