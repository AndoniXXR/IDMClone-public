Grabber (site grabber)

The Grabber explores a website and downloads the files you choose (images, audio, video, documents or the whole site to browse offline). Open it with Tasks > Run site grabber.

4-step wizard

  • Step 1: the start page, a template (all images, complete site, complete start page...), the user name and password if the site requires them, and the logout page that must not be opened.
  • Step 2: where to save the files (by category or in a folder), whether to keep the original subfolders and whether to convert links for offline browsing.
  • Step 3: which pages to explore: the whole site or some link levels on the site and on other sites, parent directories, main domain and pop-up windows.
  • Step 4: which files to download, with filters by type and minimum and maximum size.

Project window

It shows what was found in a tree and a checkable list; from there you download, add files to the IDMClone list and see the statistics. Projects are saved and appear under "Grabber projects" in the Categories panel.
