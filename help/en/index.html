IDMClone Help

IDMClone is a download manager in the style of Internet Download Manager: it splits each file across several connections, can pause and resume, sorts downloads into categories and downloads in scheduled queues.

This help is stored on your computer, next to the program. IDMClone does not open web pages to show it.

Adding downloads

  • From the browser, with the IDMClone extension: it captures the file types in Options > File types and offers the "Download this video" panel on media players.
  • Add URL (toolbar button or Tasks > Add new download).
  • Clipboard: when enabled in Options > General, a copied address whose file type is in the list.
  • Drag and drop links onto the list or the drop target.
  • Batch, import (text or .ef2) and the command line (IDMClone.exe /d URL, /a only adds to the queue, /s starts the queue, /n no windows, /q exits when done).

Where data is stored

In %APPDATA%\IDMClone: the options (config.json), the download list (downloads.json), the queues (queues.json) and the progress of each download so it can be resumed.
