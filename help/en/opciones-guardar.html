Options: Save to

  • Save to...: each category (General, Compressed, Documents, Music, Video, Programs and your own) has its file types and folder. New and Edit create or change categories. With "Change the folder of ... category to the last one selected", the folder you pick when downloading becomes the category folder.
  • Set the file date to the one provided by the server: when finished, the file takes the date given by the server (Last-Modified header) instead of today. If the server does not give one, nothing changes.
  • Temporary directory: the parts of the file are stored there while downloading and the file is moved to its folder only when complete, so it never appears half-done in its destination.
