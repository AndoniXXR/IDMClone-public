Scheduler and queues

Downloads can wait in queues: the main queue, the synchronization queue (downloads again the files that changed on the server) and the ones you create with New queue. In the download list, the "Q" column shows each file's queue.

"Schedule" tab

  • Start download on IDMClone startup.
  • Start download at HH:MM, once (on a date) or daily (on the checked days). In "Periodic synchronization", Start again every H hours M minutes.
  • Stop download at HH:MM and the number of retries per file if it fails.
  • When the queue finishes (separate checkboxes): Open the following file, Exit IDMClone and Turn off computer, with the mode (shut down, sleep or hibernate); if both of the last two are checked, it turns off. Force processes to terminate (only with "Turn off computer") closes open programs without letting them save when shutting down; when sleeping or hibernating, it forces the sleep. Use it with care. There is a 30-second countdown first that can be cancelled.
  • A queue that had nothing to download does nothing when it finishes. "Hang up modem" has no effect in IDMClone.

"Files in the queue" tab

How many files are downloaded at the same time, and the order (move up, move down, remove from queue). Completed files leave their queue, except in the synchronization queue. A file that fails goes to the end and is retried.

Buttons

Start now and Stop act on the selected queue; Apply saves the changes (closing does too). Download limits holds the same limits as Options > Connection.

Sleeping or hibernating when a queue finishes is handy at night, but the computer does not wake up by itself for the next scheduled queue.
