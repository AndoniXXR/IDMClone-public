Options: Downloads

  • Customize "Download progress" window (Edit...): whether the progress window is shown, opens minimized or is not shown, which tabs it has ("Speed limiter", "Options on completion") and whether each one has the "Hide tab" button. See the progress window.
  • Show start download dialog: the "Download file info" window (name, folder, category, "Download later").
  • Don't start downloading, just add files to the queue (only without the start dialog): what comes from the browser, the clipboard, Add URL or a dropped link does not start; it is added to the main queue, without a progress window, and a notification says so. It is downloaded when the main queue runs.
  • Show download complete dialog: the notice when finished (not shown for downloads made by a queue).
  • Start downloading while the "Download File Info" window is shown: it starts while you decide (needs the temporary directory).
  • Queue selection panels: ask which queue to use for "Download later" and for batch downloads.
  • Ignore file date changes when resuming a download: for servers that change the date on every request. Only the size is checked: if the file really changed with the same size, it could end up damaged.
  • Ask for confirmation before deleting downloads from the list, If a duplicate link is added (ask, number, overwrite or resume) and the Agent (user agent) for downloads added by hand.
  • Virus scanning settings: the antivirus that scans each finished file; [File] is the path.
