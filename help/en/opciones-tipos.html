Options: File types

  • Automatically start downloading the following file types: extensions (separated by spaces) that the browser extension captures and the clipboard monitor watches. Default restores the original list.
  • Don't start downloading automatically from the following sites: the browser extension captures nothing on those sites.
  • Don't start downloading automatically from the following addresses (Edit list...): specific addresses or addresses with a path.

The * wildcard is allowed (for example *.example.com or example.com/videos/*).
